## 02. Architectural Philosophy: The Browser as an Operating System Kernel

Modern web applications frequently collapse under the weight of bloated abstraction layers. Naishal's architecture treats the browser window as an **interactive graphics display server and task scheduler**:

* **Next-Generation Decoupled Architecture**: Front-facing experiential layers are strictly decoupled from heavyweight media payloads and edge compute services. This repository (`main-portfolio-assets`) operates as the independent **Media & CDN Layer**, guaranteeing sub-millisecond edge resolution via global Cloudflare routing without taxing client execution threads.
* **Deterministic Resource Lifecycle**: From custom WebGL canvas destruction to frame-rate-independent spring physics loops, memory leaks are eliminated through strict manual ref tracking and requestAnimationFrame isolation.
* **Zero-Trust Security Baseline**: Every inbound and outbound transaction across the ecosystem integrates cryptographic validation patterns, origin-restricted API proxies, and client-side WebCrypto heuristics.

## 03. The Aesthetic & UI/UX Engineering Flex

Every pixel within the ecosystem reflects relentless craft, combining proprietary mathematics with low-level GPU acceleration:

### 1. Liquid Glassmorphism (VisionOS Standard)
Unlike primitive flat mockups or dated neumorphism, the user interface leverages a multi-layer **Liquid Glassmorphism** design language:
* High-refraction specular borders (`border border-white/10`) layered over dynamic backdrop filters (`backdrop-blur-xl`).
* Deep volumetric luminance using calibrated radial scrims (`bg-white/5` with `shadow-[0_8px_32px_rgba(0,0,0,0.3)]`).
* Optical lamination that responds dynamically to ambient cursor trajectories.

### 2. Dynamic 3D Tilt Layouts with Zero Re-Renders
Card and interface components utilize a custom hardware-accelerated spring physics hook (`use3DTilt`):
* **0 React Re-renders**: Physics calculations (stiffness: `150`, damping: `20`, mass: `0.5`) and matrix transforms are computed directly inside `requestAnimationFrame` loops via DOM element references.
* **Photorealistic Specular Sheen**: Real-time cursor coordinates project a localized radial glare (`rgba(0, 255, 204, 0.16)`) across a 3D perspective field (`perspective: 1200px`), simulating genuine physical glass.

### 3. Custom Fluid WebGL Canvas Shaders
The hero experience features an uncompromised custom GLSL pipeline compiled through Three.js and `@react-three/fiber`:
* **Multi-Frequency Wave Dynamics**: Dual sinusoidal oscillators simulating viscous fluid displacement across normalized UV coordinates.
* **Prismatic Chromatic Aberration**: Refractive dispersion that separates RGB channels along the wavefront crests as the user's cursor traverses the canvas.
* **Cyan Metallic Sheen**: Specular liquid highlights engineered via cubic polynomial falloff curves (`pow(clamp(wave * falloff, 0.0, 1.0), 3.0)`).

## 06. The CDN Layer & Media Ingestion Pipeline

### Why This Repository Exists
High-fidelity creative portfolios demand rich, uncompressed visual demonstrations—especially **hover-to-play interactive project previews**, fluid 60fps MP4/WebM captures, and ultra-high-resolution interface mockups. Embedding these assets directly into the application bundle degrades First Contentful Paint (FCP) and clogs git version control.

`main-portfolio-assets` acts as the **dedicated, high-availability origin storage and CDN backbone** for the primary portfolio.

### Asset Delivery Schema
```
main-portfolio-assets/
├── videos/
│   ├── macos-webos-demo.mp4       # 1080p 60fps H.264 preview
│   ├── macos-webos-demo.webm      # Ultra-lightweight AV1 stream
│   ├── nexus-architecture.mp4     # Microservices visual telemetry
│   ├── cyber-portfolio-glsl.mp4   # GPU shader interaction showcase
│   └── phishguard-zk-flow.mp4     # Cryptographic validation sequence
├── posters/
│   ├── macos-webos-poster.webp    # Sub-50KB instant blur-up placeholder
│   └── nexus-poster.webp          # Refractive preview cover
└── telemetry/
    └── release-manifest.json      # Dynamic asset checksums & versioning
```

### Consumption from the Primary Web Engine
All assets hosted within this repository are served with aggressive immutable cache policies, accessed directly by the client:
```typescript
const ASSET_CDN_BASE = "https://raw.githubusercontent.com/naishal988/main-portfolio-assets/main";

export const getProjectShowcaseUri = (assetId: string, ext: 'mp4' | 'webm' | 'webp' = 'mp4') => {
  return `${ASSET_CDN_BASE}/videos/${assetId}.${ext}`;
};
```
